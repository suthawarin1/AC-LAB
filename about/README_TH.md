# About — The AC Lab

## อัปเดต v2: ภาพและฟอนต์ไทย

- แบนเนอร์ภาพใบพืชเต็มพื้นที่ พร้อมภาพแยกของแนววิจัยทั้งสามด้าน
- ภาพประจำช่วงวิจัยเปลี่ยนตามแท็บใน Research Method Network
- กดปุ่มขยายภาพเพื่อดูภาพเต็ม ปิดด้วยปุ่มกากบาทหรือ Escape
- ฟอนต์เนื้อหาไทยใช้ Anuphan หัวข้อไทยใช้ Noto Serif Thai โดยฝังใน HTML เพื่อให้เปิดดูแบบ standalone ได้
- ภาพตัวอย่างและฟอนต์มีไฟล์แยกใน `about/images` และ `about/fonts` พร้อมแหล่งที่มาและใบอนุญาตฟอนต์

เมื่อใช้ Python กำหนดภาพใน `about/site.json` ด้วย `media`, `visuals.hero`, `researchAreas[].image` และ `stages[].image` โดยพาธภาพอ้างอิงจากโฟลเดอร์ About ส่วน HTML ที่เปิดโดยตรงจะใช้ภาพที่ฝังไว้ใน `about-config`

เปิด `about/index.html` จากเมนู About ของเว็บหลัก ภาษาจะส่งต่อด้วย `?lang=th` หรือ `?lang=en` โดยไม่กลับไปผ่านหน้าต้อนรับ

## ส่วนประกอบ

1. แล็บเราคืออะไร พร้อมข้อมูลหัวหน้าห้องปฏิบัติการจากไฟล์เดิม
2. แนววิจัยด้านจีโนมิกส์พืช พฤกษเคมี และชีวการแพทย์
3. Research Method Network แบ่ง 4 ช่วง: การศึกษาพืช, การทดสอบก่อนคลินิก, การพัฒนาผลิตภัณฑ์ และการขึ้นทะเบียน/ต่อยอด

เลือกแท็บเพื่อเปลี่ยนช่วง กดจุดในแผนภาพเพื่ออ่านรายละเอียด ใช้ลูกศรซ้าย/ขวา หรือ Home/End บนแท็บได้ รองรับมือถือและการลดการเคลื่อนไหว

## แก้เนื้อหา

- ผ่าน Python: แก้ `about/site.json` แล้วรีเฟรช ไม่ต้องแก้ HTML
- เปิด HTML โดยตรง: แก้ JSON ใน `<script id="about-config">`
- `copy` คือข้อความแนะนำ, `researchAreas` คือแนววิจัย และ `stages` คือเครือข่ายวิธีวิจัย
- แต่ละ stage มี `nodes`, `edges` และรายละเอียดวิธีศึกษา สามารถปรับข้อความสองภาษาได้
- `desktop` และ `mobile` เป็นพิกัดแผนภาพคนละรูปแบบ เพื่อไม่บีบข้อความบนมือถือ
- Python ให้ข้อมูลที่ `GET /api/about` และใช้ `GET /api/site` ร่วมกับเว็บหลักเพื่อให้เมนูตรงกัน

เนื้อหาปรับจากกรอบวิจัยใน HTML เดิม ภาพพืชและหลอดทดลองเป็นภาพประกอบ รูปหัวหน้าห้องปฏิบัติการนำจากไฟล์เดิม เครือข่ายแสดงแนวทางวิจัยและความร่วมมือ ไม่ได้อ้างว่าทุกเครื่องมืออยู่ภายในแล็บ

ข้อกำหนดการขึ้นทะเบียนและการศึกษาทางคลินิกขึ้นกับประเภทผลิตภัณฑ์ จึงแสดงเส้นทางตามเงื่อนไขในแผนภาพ คำย่อ AMS ในต้นฉบับไม่มีคำขยาย จึงไม่แสดงเป็นชื่อเครื่องมือที่ยืนยันแล้ว
