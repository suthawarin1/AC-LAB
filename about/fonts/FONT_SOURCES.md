# Thai fonts

The About page embeds these unmodified fonts for reliable standalone viewing:

- Anuphan — https://fonts.google.com/specimen/Anuphan
- Noto Serif Thai — https://fonts.google.com/noto/specimen/Noto+Serif+Thai

Both fonts are distributed under the SIL Open Font License 1.1. Full licenses are provided as `OFL_Anuphan.txt` and `OFL_Noto_Serif_Thai.txt`, and are embedded in the HTML's inert `thai-font-licenses` block.

The `font-*.woff2` files contain the original Google Fonts subsets. `fonts.css` can be used when serving the fonts as separate local assets. The standalone HTML already contains its font CSS and bytes.
