แบบฟอร์มอัปเดตข้อมูลสมาชิก

สำหรับอาจารย์ นักวิจัย และสมาชิกในแล็บ กรอกหรือแก้ไขข้อมูลของตนเองแล้วกดส่ง ระบบจะส่งข้อมูลไปยัง Manager เพื่อตรวจสอบก่อนเผยแพร่บนเว็บไซต์หลัก

ไม่ต้องสมัครสมาชิกหรือเข้าสู่ระบบ — ข้อมูลที่ส่งจะยังไม่แสดงบนเว็บไซต์จนกว่า Manager จะอนุมัติ

1. เลือกโปรไฟล์ของคุณ

เลือกรายชื่อที่มีอยู่ในเว็บไซต์ เพื่อให้ Manager ทราบว่าข้อมูลนี้ต้องนำไปอัปเดตกับใคร

2. ผู้ส่งข้อมูล

ใช้สำหรับติดต่อกลับหาก Manager ต้องการสอบถามเพิ่มเติม

3. ข้อมูลที่ต้องการให้แสดง

เมื่อเลือกรายชื่อ ระบบจะเติมข้อมูลเดิมให้โดยอัตโนมัติ คุณสามารถแก้เฉพาะจุดที่ต้องการได้

คั่นแต่ละหัวข้อด้วย comma (,)

4. รูปโปรไฟล์

ไม่จำเป็นต้องอัปโหลดใหม่ หากใช้รูปเดิมให้ปล่อยไว้ได้

ยังไม่มีรูป
